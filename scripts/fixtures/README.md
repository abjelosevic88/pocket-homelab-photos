# Fixture library

The browser suite (`scripts/e2e.mjs`) and the README screenshots run against this made-up household library
instead of a real Immich server. `photos.json` gives each photo its title, date, place, album and people;
`people.json` and `faces/` are the people the library recognises. Names, dates and places are invented.

The photos are real photographs from [Unsplash](https://unsplash.com), used under the
[Unsplash License](https://unsplash.com/license) (fetched through [Lorem Picsum](https://picsum.photos)),
resized to 1024 px. The face thumbnails are crops of `ana`, `lena-in-the-sun`, `sara-reading` and
`sara-and-mia`. Thanks to the photographers:
